## 📌 Project Overview
FillSync is a comprehensive, AI-assisted form automation platform and Chrome Extension designed to eliminate repetitive data entry across job applications, university admissions, government exam portals, and travel booking platforms.

---

## 📂 Repository Structure
- **`fillsync/`** — Complete source code:
  - **`users/`** — User website (React + Vite, Tailwind CSS) & backend API (Node.js/Express, AES-256 encryption, Razorpay gateway)
  - **`extension/`** — Chromium Manifest V3 browser extension with multi-step DOM automation
  - **`superadmin/`** — Administrative management dashboard
  - **`shared-database/`** — Encrypted local storage and state management
- **Documentation & Reports:**
  - `Planning - Feature Identification(prj1).docx`
  - `PRJ-1 Project(Feasability study).docx`
  - `PRJ-1 Project(SRS).docx`
  - `PRJ-1 course handout.pdf`
